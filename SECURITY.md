# Security reports

This verifier handles firmware checks for a device that may protect funds. Please do not use a public issue to disclose a vulnerability before it can be assessed. If private vulnerability reporting is enabled, use the repository's [Security tab](https://github.com/Schnuartz/verify-clavastack/security) for a problem in this website or its catalog. Otherwise contact the repository owner privately via a channel published on their GitHub profile. For a vulnerability in Specter firmware itself, report it to [the upstream Specter project](https://github.com/cryptoadvance/specter-diy/security).

Include the affected release, a reproducible test and the expected versus actual verification result. Never send seed words, private keys or wallet backups.

This site compares a local file hash with a catalog built from pinned upstream OpenPGP keys. It does not attest a physical device or prove that the hosting site has not been replaced; see [TRUST.md](TRUST.md).
